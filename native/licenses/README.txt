Telecat 0.1.0 — third-party notices

Generated by scripts/notices.py from Cargo.lock for the build host. Normal and
build dependencies are included conservatively; some feature-unified optional
packages may not contribute executable code. Each entry identifies its declared
license, upstream repository/source archive, authors and full license texts.
Repeated texts are deduplicated by SHA-256 prefix in the LICENSE TEXTS section.
For crates published without a license file, the checked-in upstream declaration,
source-header notices and manifest authors are retained, with full common MIT
and Apache-2.0 license bodies included at the end. License alternatives retain
their upstream declarations. System frameworks and system fonts are not bundled.

Vendored/modified sources in this distribution's native/ source tree:
- vendor/mysql_async: MySQL CLIENT_FOUND_ROWS capability and protocol safeguards.
  Upstream blackbeam/mysql_async; MIT OR Apache-2.0.
- vendor/tokio-postgres: PostgreSQL text-format result decoding and defensive row
  range checks. Upstream rust-postgres/rust-postgres; MIT OR Apache-2.0.
- vendor/gpui-base: editor viewport, UTF-16, multi-cursor/input integration and
  drawing fixes. Upstream longbridge/gpui-kit; Apache-2.0.
- vendor/gpui-pre-macos: on-demand frame scheduling, idle display-link shutdown,
  full-content window layout and vibrancy. Upstream zed-industries/zed snapshot
  93d745668805029476e6d7fbb19652116fed51de; Apache-2.0.
- vendor/gpui-pre-apple: correct source-over destination-alpha blending for
  transparent windows. Same Zed snapshot; Apache-2.0.
- editor/engine: input/editor subset from gpui-kit, with SQL editor multi-cursor,
  completion, focus, selection, scrolling and caret lifecycle adaptations;
  Apache-2.0. Original license retained in editor/engine/LICENSE-APACHE.
- reference/gpui-kit: unmodified reference checkout; Apache-2.0 (code). Its docs
  license applies to documentation, which is not included in the app bundle.
- editor: SQL formatter and CodeMirror SQL dialect data ports (MIT); original
  copyright notices reproduced below.
- db/src/mysql-errors.rs: mysql2 error-name mapping port (MIT).

The MPL-2.0 packages listed below are unmodified. Their corresponding source is
available at the exact crates.io source-archive URLs included in their entries.
All local patch sources are in the native/vendor and native/editor/engine paths
above; no external database client library is bundled. The application icon is
the project's build/icon.png; the bundle contains its generated ICNS rendition.
